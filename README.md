# Tenbin Game

スマホを1台ずつ回して遊ぶ、0から100の数字選択ゲームです。

## ルール

- 参加者は0から100までの整数を選びます。
- 全員の平均値に0.8をかけた値が目標値です。
- 目標値に一番近い参加者が勝者です。勝者の得点は変わりません。
- 勝者以外は通常-1点です。
- 勝者がニアピン範囲に入った場合、勝者以外は-2点です。
- 同じ数字を選んだ参加者が1組でもいた場合、そのラウンドは無効となり全員-1点です。
- 目標値に対して同距離の参加者が複数いた場合、そのラウンドは無効となり全員-1点です。
- 生存者が2人で0と100が出た場合だけ、100を選んだ参加者が勝者です。
- -10点以下になった参加者は次のラウンドから脱落します。
- 最後に残った1人が優勝です。
